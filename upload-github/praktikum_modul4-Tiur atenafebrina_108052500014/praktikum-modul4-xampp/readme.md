# Petunjuk Setup & Penggunaan Proyek - Praktikum Modul 4

Dokumen ini berisi panduan untuk menjalankan dan mengonfigurasi proyek Praktikum Modul 4 di berbagai lingkungan lokal (local environment).

---

## Cara Penempatan Folder Proyek

Anda dapat memilih salah satu cara penempatan folder berikut sesuai dengan aplikasi local server yang Anda gunakan:

1. **Laragon**
   - Simpan / extract folder proyek di dalam direktori `www`:
     `C:\laragon\www\praktikum_modul4_laragon_tiur`

2. **XAMPP**
   - Simpan / extract folder proyek di dalam direktori `htdocs`:
     `C:\xampp\htdocs\praktikum_modul4_xampp`

3. **Virtual Environment (flyenv)**
   - Simpan folder proyek `praktikum_modul4_flyenv` di direktori pilihan Anda.
   - Jalankan server lokal menggunakan environment pilihan Anda.

---
## Cara Menjalankan Aplikasi

1. Buka aplikasi web server lokal Anda (Laragon / XAMPP / flyenv).
2. Aktifkan service/modul yang diperlukan.
3. Buka web browser dan akses URL berikut sesuai lingkungan yang digunakan:

   - **Via Laragon:**
     - `http://praktikum_modul4_laragon_tiur.test`
     - `http://localhost/praktikum_modul4_laragon_tiur`

   - **Via XAMPP:**
     - `http://localhost/praktikum_modul4_xampp`

   - **Via flyenv:**
     - `http://localhost:8000/nama_file.php`
